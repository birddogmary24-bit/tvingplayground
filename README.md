# 🎬 TVING Playground

TVING OTT 플랫폼 기반 모바일 큐레이션 놀이터 서비스 프로토타입

## 스크린 구성
- **홈**: 히어로 배너 + VOD 카드 + 쇼츠/클립 밴드 + 미니게임
- **쇼츠**: 9:16 세로형 숏폼 그리드
- **클립**: 16:9 가로형 하이라이트
- **게임**: 캐릭터 퀴즈, 추천 룰렛 (포인트 보상)
- **일정**: 요일별 공개 편성표
- **MY**: 포인트/구매 내역/구독 관리

## 콘텐츠
환승연애4, 친애하는X, 판사 이한영, 유퀴즈온더블럭, 대탈출 더스토리, 쇼미더머니12, 우주를 줄게

## 시작하기
```bash
npm install
npm run dev
```

## 기술 스택
- React 18 + Vite
- Anthropic API (이미지 검색)

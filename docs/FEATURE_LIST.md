# FEATURE LIST

> 최종 업데이트: 2026-03-01

## 핵심 기능

### 1. VOD 브라우징
- 7개 콘텐츠 카드 가로 스크롤
- 태그 표시 (HOT/NEW/TOP/FREE/LIVE)
- 카드 클릭 → 상세 모달
- 무료 VOD 모아보기 (모달)

### 2. 쇼츠 탭
- 9:16 세로형 숏폼 그리드
- 쇼츠 카드 클릭 → TVING 링크 이동

### 3. 클립 탭
- 16:9 가로형 하이라이트 리스트
- 클립 카드 클릭 → TVING 링크 이동

### 4. 미니게임 (게임 탭)

#### 4.1 캐릭터 퀴즈
- 환승연애4 기반 4문제
- 4지선다 객관식
- 정답당 15P (최대 60P)
- 정답 초록/오답 빨강 하이라이트, 0.7초 후 다음 문제

#### 4.2 추천 룰렛
- 7개 콘텐츠 중 랜덤 1개 추천
- 회전 애니메이션 (conic-gradient 기반)
- 1회 돌리기당 30P 고정

#### 4.3 명장면 모드 ✨ NEW
- **형식**: 객관식 4지선다 (A/B/C/D)
- **문제 풀**: 15문제 (TVING CDN 실제 이미지)
- **문제 유형**:
  - 프로그램 맞추기: "이 장면은 어떤 프로그램인가요?"
  - 출연진 맞추기: "○○의 MC 조합은?", "○○ 역을 맡은 배우는?"
  - 상황 맞추기: "이 장면의 상황은?", "이 장면의 분위기는?"
- **대상 콘텐츠**: 환승연애4, 대탈출 더스토리, 유퀴즈온더블럭, 쇼미더머니12, 친애하는X, 판사 이한영, 우주를 줄게
- **게임 흐름**: 15문제풀 → 랜덤 6문제 추출 → 순차 풀이 → 결과 화면
- **보상**: 정답당 13P (최대 78P)
- **피드백**: 정답 초록(#34C759)/오답 빨강(#FF2D55) 하이라이트 → 0.7초 후 전환
- **프로그레스바**: 보라색(#5856D6), 문제 진행률 표시

#### 4.4 끝말잇기
- 드라마 제목 잇기 (미구현, 스텁만 존재)
- 40P 표시

### 5. 회원 시스템 ✨ NEW
- **자동 가입**: 첫 방문 시 랜덤 프로필 자동 생성
- **닉네임**: 형용사+동물 조합 (225가지, 예: "용감한수달")
- **아바타**: 동물 이모지 (닉네임과 매칭)
- **저장소**: localStorage (`"tving_user"` 키)
- **웰컴 포인트**: 120P 자동 지급
- **데이터 유지**: 브라우저 데이터 삭제 전까지 영구 유지
- **상세 정책**: [MEMBERSHIP_POLICY.md](./MEMBERSHIP_POLICY.md) 참고

### 6. 레벨 시스템 ✨ NEW
- 6단계: 🌱뉴비(0P) → ⭐루키(100P) → 🔥챌린저(300P) → 💎마스터(600P) → 👑레전드(1000P) → 🏆티빙킹(2000P)
- 누적 포인트(`totalPt`) 기준, 포인트 소비해도 레벨 하락 없음
- MY 탭에 레벨 프로그레스바 표시

### 7. 랭킹 보드 ✨ NEW
- MY 탭 내 "🏆 랭킹 보드" 섹션
- TOP 3 포디움 (🥇🥈🥉 메달) + 4위 이하 리스트
- 가짜 유저 15명 + 실제 유저 혼합 정렬
- 실제 유저 "(나)" 노란색 하이라이트

### 8. 게임 히스토리 ✨ NEW
- MY 탭 내 "📋 게임 기록" 섹션
- 게임 아이콘 + 이름 + 상대시간 + 정답률 + 획득 포인트
- localStorage에 플레이 기록 누적 저장

### 9. 포인트 시스템
- **이중 트래킹**: 사용 가능(`pt`) / 누적(`totalPt`) 분리
- **획득**: 게임 보상, 웰컴 보너스
- **소비**: 유료 VOD 구매 (`pt`만 차감, `totalPt` 영향 없음)

### 10. 공개 일정 (일정 탭)
- 요일별 편성표
- 오늘 하이라이트

### 11. 히어로 배너
- 3개 콘텐츠 자동 회전 (4초 간격)
- "클립 보러가기" → TVING URL 이동

### 12. 상세 모달
- 콘텐츠 정보 + 클립/쇼츠 리스트
- "TVING에서 보기" 버튼 → TVING URL 이동

### 13. 3Pack 배너
- Disney+ / TVING / Wavve 로고 배너
- TVING 3Pack 테마 페이지 링크

### 14. 헤더
- TVING 로고 + "놀이터" 뱃지
- 아바타 + 닉네임 + 레벨뱃지 + 포인트 표시
- 로그아웃 버튼

## 1. 회원 가입 정책

### 1.1 자동 가입 방식
- **별도 회원가입 폼 없음** — 첫 방문 시 자동으로 프로필 생성
- 백엔드/DB 없이 **localStorage 기반 MVP**
- 사용자 조작 없이 즉시 서비스 이용 가능

### 1.2 프로필 자동 생성 규칙
| 항목 | 생성 규칙 | 예시 |
|------|----------|------|
| **유저 ID** | `"usr_" + Math.random().toString(16).slice(2,8)` | `usr_a7f3b2` |
| **닉네임** | 형용사(15종) + 동물(15종) 조합 (225가지) | `용감한수달`, `행복한곰` |
| **아바타** | 동물 이모지 (닉네임 동물과 매칭) | 🦦, 🐻 |
| **웰컴 포인트** | 120P 자동 지급 | - |
| **초기 레벨** | Lv.2 루키 (120P ≥ 100P 기준) | ⭐ 루키 |

### 1.3 닉네임 풀
**형용사 (15종)**: 행복한, 용감한, 빠른, 귀여운, 멋진, 신비한, 당당한, 재밌는, 따뜻한, 반짝이는, 배고픈, 졸린, 활발한, 현명한, 유쾌한

**동물 (15종)**: 곰, 사자, 토끼, 펭귄, 고양이, 강아지, 여우, 올빼미, 코알라, 판다, 호랑이, 돌고래, 다람쥐, 수달, 너구리

**아바타 이모지 (동물과 1:1 매핑)**: 🐻 🦁 🐰 🐧 🐱 🐶 🦊 🦉 🐨 🐼 🐯 🐬 🐿️ 🦦 🦝

## 2. 데이터 저장 정책

### 2.1 저장 위치
- **localStorage** key: `"tving_user"`
- 브라우저/기기별 독립 (크로스 디바이스 동기화 없음)

### 2.2 데이터 스키마
```json
{
  "id": "usr_a7f3b2",
  "nickname": "용감한수달",
  "avatar": "🦦",
  "totalPt": 420,
  "gamesPlayed": 12,
  "history": [
    {
      "game": "famousscene",
      "pts": 52,
      "correct": 4,
      "total": 6,
      "ts": 1709280000000
    }
  ]
}
```

### 2.3 데이터 수명
- **유지 조건**: 브라우저 캐시/데이터가 삭제되지 않는 한 영구 유지
- **삭제 조건**: 브라우저 데이터 삭제, 시크릿 모드, 다른 브라우저/기기
- **로그아웃**: 화면 상태만 초기화, localStorage 데이터는 유지

### 2.4 히스토리 저장
- 게임 플레이 기록은 `history` 배열에 누적 저장
- 각 기록에는 게임 타입, 획득 포인트, 정답률, 타임스탬프 포함
- 현재 최대 저장 수 제한 없음 (향후 최근 50건 제한 고려)

## 3. 포인트 시스템

### 3.1 이중 트래킹 (Dual Point Tracking)

| 포인트 종류 | 변수 | 용도 | 변동 |
|-----------|------|------|------|
| **사용 가능 포인트** | `pt` (useState) | 콘텐츠 구매 | 보상으로 증가, 구매로 감소 |
| **누적 포인트** | `usr.totalPt` (localStorage) | 레벨 산정, 랭킹 정렬 | 보상으로만 증가 (감소 안함) |

### 3.2 포인트 획득 경로
| 경로 | 획득량 | 조건 |
|------|-------|------|
| **웰컴 보너스** | 120P | 첫 가입 시 1회 |
| **캐릭터 퀴즈** | 정답당 15P (최대 60P) | 4문제 중 정답 수 × 15P |
| **추천 룰렛** | 30P (고정) | 1회 돌리기당 |
| **명장면 모드** | 정답당 13P (최대 78P) | 6문제 중 정답 수 × 13P |

### 3.3 포인트 소비
- 유료 VOD 콘텐츠 구매 (예: 친애하는X 3000P, 대탈출 더스토리 2500P)
- `pt`(사용 가능 포인트)에서만 차감
- `totalPt`(누적 포인트)는 영향 없음 → 레벨/랭킹 하락 없음

## 4. 레벨 시스템

### 4.1 레벨 테이블
| 레벨 | 이름 | 뱃지 | 최소 누적 포인트 | 뱃지 색상 |
|-----|------|-----|----------------|----------|
| Lv.1 | 뉴비 | 🌱 | 0P | #8E8E93 (회색) |
| Lv.2 | 루키 | ⭐ | 100P | #34C759 (녹색) |
| Lv.3 | 챌린저 | 🔥 | 300P | #FF9500 (주황) |
| Lv.4 | 마스터 | 💎 | 600P | #5856D6 (보라) |
| Lv.5 | 레전드 | 👑 | 1,000P | #FFD60A (금색) |
| Lv.6 | 티빙킹 | 🏆 | 2,000P | #FF2D55 (레드) |

### 4.2 레벨 산정 기준
- **누적 포인트(`totalPt`)** 기준 (사용 포인트 아님)
- 포인트 소비해도 레벨 하락 없음
- 레벨업은 실시간 반영 (게임 완료 즉시)

### 4.3 레벨 프로그레스바
- MY 탭에 현재 레벨 → 다음 레벨 진행률 표시
- 계산식: `(현재포인트 - 현재레벨최소) / (다음레벨최소 - 현재레벨최소) × 100%`
- 최고 레벨(Lv.6) 도달 시 100% 고정

## 5. 랭킹 시스템

### 5.1 랭킹 구성
- **실제 유저 1명** + **가짜 유저(봇) 15명** = 총 16명
- `totalPt` 기준 내림차순 정렬

### 5.2 가짜 유저 분포
| 순위대 | 닉네임 | 포인트 | 레벨 |
|-------|--------|--------|------|
| 상위 | 빠른사자 | 1,850P | Lv.5 👑 |
| 상위 | 용감한독수리 | 1,420P | Lv.5 👑 |
| 상위 | 귀여운판다 | 1,100P | Lv.5 👑 |
| 중위 | 신비한올빼미~당당한여우 | 650~980P | Lv.4 💎 |
| 중위 | 활발한토끼~반짝이는고양이 | 350~500P | Lv.3 🔥 |
| 하위 | 현명한수달~배고픈강아지 | 120~280P | Lv.2 ⭐ |
| 하위 | 졸린펭귄, 행복한다람쥐 | 30~60P | Lv.1 🌱 |

### 5.3 랭킹 UI
- **TOP 3 포디움**: 1위(중앙, 높은 바) / 2위(좌측) / 3위(우측) + 🥇🥈🥉 메달
- **4위 이하**: 리스트형 (순위번호 + 아바타 + 닉네임 + 레벨뱃지 + 포인트)
- **실제 유저 하이라이트**: 노란색 배경 + "(나)" 라벨 표시

### 5.4 향후 개선 방향
- 가짜 유저 포인트에 미세 랜덤 변동 추가 (리얼리티 향상)
- 주간/월간 랭킹 리셋 기능
- 서버 기반 실제 다중 유저 랭킹 (백엔드 구축 시)

## 6. 게임 히스토리

### 6.1 기록 항목
| 필드 | 타입 | 설명 |
|------|------|------|
| `game` | string | 게임 타입 ID (`quiz`, `roulette`, `famousscene`) |
| `pts` | number | 획득 포인트 |
| `correct` | number | 정답 수 (퀴즈 계열만) |
| `total` | number | 전체 문제 수 (퀴즈 계열만) |
| `ts` | number | 플레이 시각 (Unix timestamp ms) |

### 6.2 표시 형식
```
🎬 명장면 모드
  1분 전 · 2/6         +26P
```
- 게임 아이콘 + 이름
- 상대 시간 (방금 전 / n분 전 / n시간 전 / n일 전)
- 정답률 (correct/total)
- 획득 포인트

## 7. 로그인/로그아웃 정책

### 7.1 자동 로그인
- 앱 로드 시 localStorage 체크
- 유저 데이터 존재 → 자동 로그인 (별도 인증 없음)
- 유저 데이터 없음 → 자동 생성 + 웰컴 포인트

### 7.2 로그아웃
- 헤더의 "로그아웃" 버튼 클릭
- **localStorage 데이터 유지** (삭제하지 않음)
- 화면 상태만 초기화 → 새로고침 시 자동 재로그인

### 7.3 계정 삭제
- 현재 별도 삭제 기능 없음
- 브라우저 데이터 삭제 시 자동 삭제
- 향후: "회원 탈퇴" 버튼 추가 시 localStorage 키 삭제로 구현

## 8. 기술적 한계 (MVP)

| 항목 | 현재 상태 | 향후 개선 |
|------|----------|----------|
| 저장소 | localStorage (브라우저 한정) | 서버 DB + API |
| 인증 | 없음 (자동 생성) | OAuth / 소셜 로그인 |
| 크로스 디바이스 | 미지원 | 서버 동기화 |
| 부정 방지 | 없음 (localStorage 조작 가능) | 서버사이드 검증 |
| 닉네임 중복 | 허용 (유저 ID로 구분) | 유니크 닉네임 체크 |
| 히스토리 용량 | 무제한 | 최근 50건 제한 |

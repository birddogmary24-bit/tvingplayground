# PRD — TVING Playground 제품 요구사항 문서

> 최종 업데이트: 2026-03-01 (PWA + 끝말잇기 추가)

---

## 1. 제품 개요

### 1.1 비전
TVING OTT 플랫폼을 모티브로 한 **모바일 큐레이션 놀이터** 프로토타입.
실제 TVING 콘텐츠 데이터를 기반으로, 기존 OTT 앱의 브라우징 경험에 **게이미피케이션 요소**(미니게임, 포인트, 레벨, 랭킹)를 결합한 실험적 서비스.

### 1.2 목표
| 목표 | 설명 |
|------|------|
| 콘텐츠 탐색 | 실제 TVING 콘텐츠(VOD/클립/쇼츠)를 자연스럽게 브라우징 |
| TVING 유입 | 모든 콘텐츠 클릭이 실제 TVING 페이지로 직접 연결 |
| 체류 시간 증대 | 미니게임 + 포인트 시스템으로 반복 방문 유도 |
| 3Pack 프로모션 | Disney+/TVING/Wavve 번들 상품 인지도 향상 |

### 1.3 타겟 사용자
- TVING 기존/잠재 사용자
- 모바일 우선 사용자 (max-width 430px 기준)
- 가벼운 게임과 콘텐츠 탐색을 동시에 즐기는 2030 세대

## 3. 콘텐츠 정책

### 3.1 콘텐츠 수
- MVP: **7개 프로그램** (고정)
- 각 프로그램별: 에피소드, 클립(가로), 쇼츠(세로) 포함

### 3.2 콘텐츠 라인업
| ID | 제목 | 장르 | 태그 | 무료 | 가격 |
|----|------|------|------|------|------|
| ex4 | 환승연애4 | 예능·리얼리티 | HOT | O | - |
| dx | 친애하는X | 드라마·스릴러 | NEW | X | 3,000P |
| jg | 판사 이한영 | 드라마·법정 | TOP | O | - |
| uq | 유퀴즈온더블럭 | 예능·토크 | FREE | O | - |
| ge | 대탈출 더스토리 | 예능·추리 | HOT | X | 2,500P |
| sm | 쇼미더머니12 | 예능·힙합 | LIVE | O | - |
| uv | 우주를 줄게 | 드라마·로맨스 | NEW | O | - |

### 3.3 이미지 정책
- **포스터**: TVING CDN (`image.tving.com`) 세로 이미지 (CAIP0200, 2:3 비율)
- **배너**: TVING CDN 가로 이미지 (CAIP0900, 16:9 비율)
- **썸네일**: 클립/쇼츠 개별 썸네일 URL
- **폴백**: 이미지 로드 실패 시 SVG 기반 `FallbackPoster` 자동 생성 (제목 해시 기반 색상)

### 3.4 링크 정책
- **VOD**: `https://www.tving.com/contents/E{코드}` (E-코드)
- **클립**: `https://www.tving.com/contents/L{코드}` (L-코드)
- **쇼츠**: 해당 프로그램의 첫 번째 클립 URL로 대체
- **모든 클릭**: 새 탭(`_blank`)으로 TVING 실제 페이지 이동

## 4. 디자인 요구사항

### 4.1 레이아웃
- **모바일 퍼스트**: `max-width: 430px`, 센터 정렬
- **풀스크린**: `min-height: 100vh`, 다크 배경
- **하단 탭바**: 6개 탭 (홈/쇼츠/클립/게임/일정/MY), 고정 위치

### 4.2 컬러 시스템
| 용도 | 컬러 | 코드 |
|------|------|------|
| 배경 | 블랙 | `#000` |
| 카드 배경 | 다크 그레이 | `#1C1C1E` |
| 메인 (TVING Red) | 레드 | `#FF2D55` |
| 포인트 (골드) | 옐로우 | `#FFD60A` |
| HOT 태그 | 레드 | `#FF2D55` |
| NEW 태그 | 퍼플 | `#5856D6` |
| TOP 태그 | 오렌지 | `#FF9500` |
| FREE 태그 | 그린 | `#34C759` |
| LIVE 태그 | 오렌지 | `#F5A623` |

### 4.3 타이포그래피
- **주 폰트**: `Noto Sans KR` → `-apple-system` → `BlinkMacSystemFont` → `sans-serif`
- **헤더 제목**: 22px, 800 weight
- **섹션 제목**: 17–20px, 700 weight
- **본문**: 13–14px, 400–500 weight
- **캡션**: 10–12px, 500 weight

### 4.4 컴포넌트 스타일
- **카드**: `border-radius: 10–14px`, 인라인 스타일
- **버튼**: `border-radius: 12–24px`, 그라데이션 배경 활용
- **모달**: 하단 시트 형태, `border-radius: 20px 20px 0 0`
- **태그**: 라운드 뱃지, 배경 + 텍스트 색상 구분

## 5. 게임 정책

### 5.1 게임 라인업
| 게임 | 형식 | 보상 | 대상 콘텐츠 |
|------|------|------|------------|
| 캐릭터 퀴즈 | 4지선다 4문제 | 정답당 15P (최대 60P) | 환승연애4, 친애하는X, 유퀴즈, 쇼미더머니 |
| 추천 룰렛 | 랜덤 1회 | 30P (고정) | 전체 7개 콘텐츠 |
| 명장면 모드 | 이미지 + 4지선다 6문제 | 정답당 13P (최대 78P) | 전체 7개 콘텐츠 (15문제풀 → 6문제 랜덤) |
| 야옹이 키우기 | 육성 시뮬레이션 | 빨간약/파란약 (별도 시스템) | 환승연애4 출연진 |
| 끝말잇기 | 채팅 UI 1:1 AI 대결, 15초 타이머 | 최대 40P (`min(10+round*5,40)`) | ~200단어 DB (TVING/드라마/명사) |

### 5.2 야옹이 키우기 상세
- **프로필**: 환승연애4 출연진 6명 중 택 1 (집사 역할)
- **고양이**: 8종 (치즈냥/까만냥/하양냥/삼색냥/러시안블루/샴냥/턱시도냥/스코티쉬냥)
- **레벨**: 1~99 (빨간약 + 파란약 소비로 레벨업)
- **빨간약 획득**: 쇼츠/클립/VOD 시청 시 +1
- **파란약 획득**: 출석체크 시 +1 (1일 1회)
- **데이터 저장**: `localStorage("catgame_save")`에 독립 저장

## 6. 포인트/레벨/랭킹 정책

> 상세 정책은 [MEMBERSHIP_POLICY.md](./MEMBERSHIP_POLICY.md) 참고

### 6.1 핵심 규칙
- **이중 포인트**: 사용 가능(`pt`) / 누적(`totalPt`) 분리
- **레벨 산정**: `totalPt` 기준 (소비해도 레벨 하락 없음)
- **랭킹**: 가짜 유저 15명 + 실제 유저, `totalPt` 내림차순
- **히스토리**: 최근 50건까지 저장, 게임타입/포인트/정답률/시각 기록

## 7. 기술 제약 (MVP)

| 항목 | 현재 | 향후 |
|------|------|------|
| 아키텍처 | 단일 App.jsx (~1,010줄) | 컴포넌트 분리 |

| 인증 | localStorage 자동 생성 | OAuth/소셜 로그인 |
| 배포 | Vercel 정적 사이트 | Vercel + API Routes |
